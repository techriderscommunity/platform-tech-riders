# Hallmark Bridge Capability Spec

## Capability
Integrate Hallmark visual exploration as an optional input while preserving BoostDesign UX governance.

## Inputs
- Visual brief or redesign target.
- Optional reference screenshot/URL.
- Brand and domain constraints.

## Outputs
- Visual direction proposal.
- Semantic token mapping recommendations.
- Accessibility and consistency validation report.
- Action plan to productionize accepted visual decisions.

## Acceptance Criteria
- Hallmark usage is explicit and optional.
- Output includes token normalization plan.
- Output includes WCAG and component-state checks.
- Conflicts are resolved in favor of BoostDesign governance.

## Dependencies
- `skills/hallmark/SKILL.md`
- `templates/hallmark-handoff.md`
- `examples/hallmark-to-ux-flow.md`
- `skills/ux-audit/SKILL.md`
